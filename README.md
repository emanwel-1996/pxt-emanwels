# Emanwel's

## Cool functions

### Games
- Rock Paper Scissors game
    - press button A to switch hands and button B to confirm it
- Radio Rock Paper Scissors game
    - press button A to switch hands and button B to confirm it
    - the radio group must be set before calling the function
- Reflexes game
    - press a button depending on what is shown on the screen
    - *A* means button A, *B* means button B, *+* means both button A and button B, and *O*
- Memory Games
    - press the sequence of buttons or pins shown in screen once the display ends
    - *A* means button A, *B* means button B, *+* means both button A and button B, *0* means pin P0, *1* means pin P1, *2* means pin P2, and *L* means the touch logo pin
### Tools
- Latin script to Morse Code converter
- Morse code to Latin script converter
- Random string selector
